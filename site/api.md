# Rust API

The API reference for every crate is generated by `cargo doc` from the doc comments and is published beside this site.

| Crate | API reference |
|---|---|
| `oplstream` | [oplstream](/api/oplstream/index.html) |
| `undertone-mini` | [undertone_mini](/api/undertone_mini/index.html) |
| `undertone-dsp` | [undertone_dsp](/api/undertone_dsp/index.html) |
| `undertone-opl` | [undertone_opl](/api/undertone_opl/index.html) |
| `undertone-sound` | [undertone_sound](/api/undertone_sound/index.html) |

The two planned crates, `undertone-opl` and `undertone-sound`, are empty until their code moves in from the studio.

To build the same pages locally:

```sh
RUSTDOCFLAGS='-D warnings' cargo doc --workspace --no-deps --open
```

Nothing is published to crates.io yet, so the API is available here and from a checkout only.
